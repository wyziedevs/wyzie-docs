# Wyzie Subs Sources

<TP id="subs.sources.p1" />

## Using Sources

Use the `source` parameter to specify which provider(s) to query:

```
/search?id=tt3659388&source=charlie&key=YOUR_KEY
/search?id=tt3659388&source=charlie,lima&key=YOUR_KEY
/search?id=tt3659388&source=all&key=YOUR_KEY
```

## API Endpoint

<TP id="subs.sources.api.p1" />

```
GET /sources
```

Returns:
```json
{
  "sources": ["charlie", "foxtrot", "india", "juliet", "lima", "mike", "november"],
  "free": ["charlie", "lima"],
  "paid": ["foxtrot", "india", "juliet", "mike", "november"],
  "tiered": [
    { "key": "charlie", "name": "charlie", "tier": "free", "tags": [] },
    { "key": "foxtrot", "name": "foxtrot", "tier": "paid", "tags": ["anime"] }
  ],
  "allFree": false
}
```

- `free`: <T id="subs.sources.api.free" />
- `paid`: <T id="subs.sources.api.paid" />
- `tiered`: one entry per enabled source with its `key` (the value to pass as `source`), display `name`, `tier` (`free` or `paid`), and `tags` (for example `anime`). The example above is shortened.
- `allFree`: <T id="subs.sources.api.allFree" />

### Scoping to a key

<TP id="subs.sources.scope.p1" />

```
GET /sources?key=YOUR_KEY
```

<TP id="subs.sources.scope.p2" />

```json
{
  "sources": ["charlie", "foxtrot", "india", "juliet", "lima", "mike", "november"],
  "free": ["charlie", "lima"],
  "paid": ["foxtrot", "india", "juliet", "mike", "november"],
  "tiered": [
    { "key": "charlie", "name": "charlie", "tier": "free", "tags": [], "available": true }
  ],
  "key": { "valid": true, "type": "free" },
  "available": ["charlie", "lima"],
  "restricted": ["foxtrot", "india", "juliet", "mike", "november"],
  "allFree": false
}
```

- `available`: <T id="subs.sources.scope.available" />
- `restricted`: <T id="subs.sources.scope.restricted" />
- `key.type`: <T id="subs.sources.scope.keyType" />
- `key.valid` <T id="subs.sources.scope.keyValid" />

You can also view the real-time status of all sources at [sub.wyzie.io/status](https://sub.wyzie.io/status).

## Source Details

Sources are exposed under NATO codenames. Pass the codename as the `source` value; `source=all` works for every key and queries each source that key can use. The list below reflects the live `/sources` response and can change, so fetch it at runtime rather than hardcoding it.

| Source       | Tier | Tags  |
| ------------ | ---- | ----- |
| **charlie**  | Free |       |
| **foxtrot**  | Pro  | anime |
| **india**    | Pro  |       |
| **juliet**   | Pro  | anime |
| **lima**     | Free |       |
| **mike**     | Pro  | anime |
| **november** | Pro  | anime |
