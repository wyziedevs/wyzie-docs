    const data: SubtitleData[] = await searchSubtitles({ tmdb_id: 286217, format: "srt", key: "YOUR_KEY" });

  </Tabs.Tab>
  <Tabs.Tab>
    ```ts
    import { getSources, getSourcesInfo } from "wyzie-lib";


    const sources = await getSources();
    console.log(sources); // live codenames, e.g. ["charlie", "foxtrot", "india", "juliet", "mike"]

    // Full /sources response; with a key it also lists what that key can use.
    const info = await getSourcesInfo("YOUR_KEY");
    console.log(info.free, info.paid, info.available);
    ```

  </Tabs.Tab>
  <Tabs.Tab>
    ```ts
    import { searchSubtitles, WyzieError } from "wyzie-lib";


    try {
      const data = await searchSubtitles({ tmdb_id: 286217, key: "YOUR_KEY" });
      if (data.length === 0) console.log("No subtitles for this title");
    } catch (error) {
      if (error instanceof WyzieError) {
        console.log(error.status, error.apiMessage, error.details);
        if (error.status === 402) console.log("Top up:", error.body?.topup);
      } else {
        throw error; // bad parameters or a network failure
      }
    }
    ```

### Errors

`searchSubtitles` resolves to an empty array when nothing matches. Any other refusal from the API rejects with a `WyzieError` (exported by the package) that carries:

- `status`: the HTTP status (401 no key, 402 Pro balance used up, 403 invalid key or key on hold, 429 daily limit reached, 503 every requested source paused or a brief outage)
- `apiMessage` and `details`: the API's own message, e.g. `"Key on hold"`
- `body`: the full JSON error, with extras such as `topup`, `reset_at`, `reinstate`, or `offline` (the paused sources)

`parseToVTT`, the TMDB helpers, `getSources`, and `getSourcesInfo` reject with a `WyzieError` the same way. Invalid parameters (no ID, or a season without an episode) and network failures reject with a plain `Error`. `parseToVTT` converts SRT to WebVTT and returns files that are already WebVTT unchanged.

### Configuration

<TP id="subs.pkg.config.p1" />

```ts
import { configure, searchSubtitles, parseToVTT } from 'wyzie-lib';


configure({ 
  baseUrl: 'https://my-custom-subtitle-scraper.com',
  key: 'YOUR_KEY',
});


const subtitles = await searchSubtitles({
  tmdb_id: 123456,
  language: "en"
});
```
