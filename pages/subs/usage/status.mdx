# Status API

<TP id="subs.status.p1" />

```bash
curl https://sub.wyzie.io/status/api?days=7
```

## Using It in Your App

<TP id="subs.status.use.p" />

```js
const report = await fetch('https://sub.wyzie.io/status/api?days=0').then((r) =>
  r.json(),
);
const live = Object.values(report.sources)
  .filter((s) => s.listed)
  .map((s) => s.name);
if (report.status !== 'operational') console.warn(report.summary);
```
